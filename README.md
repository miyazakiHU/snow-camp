# 潮風工房 — 島から島へ

小さな修理ロボットが、流木から部品をつくり、3つの島を復旧するブラウザゲームです。題名は開発中の仮称です。

## 遊び方

画面をドラッグ、または矢印キー・WASDで移動します。短くタップ／クリックした場所へは自動で歩きます。

流木に近づいて資材を回収し、加工台へ運ぶと部品ができます。部品を港から出荷するとコインがたまり、近づくと回収できます。丸い投資札の上で立ち止まると、荷かご・加工設備の強化や、回収係・配達係の雇用が進みます。

出荷とは別に、部品を修理場所へ届けて島を完成させます。全設備の購入は必須ではありません。加工台の近くにいるプレイヤーは、配達係より先に部品を受け取れます。

## 3つの島

| 島 | 目標 | 判断の違い |
|---|---|---|
| はじまりの浜 | 部品72個で小舟を修理 | 運搬量、設備、スタッフへの投資 |
| 運河の港 | 部品96個で水門を修理 | 東の橋を回るか、90コインで近道の橋を直すか |
| 灯台の島 | 部品112個で灯台を修理し、注文船3件に納品 | 修理用と注文用に部品を配分 |

注文船は45秒周期で訪れ、最初の25秒間に納品できます。未完成の注文に納めた部品は次の入港まで残ります。時間内に完成しなくても没収されません。通常出荷と注文報酬は、それぞれの場所で回収します。

## 航路と引き継ぎ

島を完成させると、復旧記録・記念品・最短クリア記録が残ります。次の島へは、解放した道具から一つ持ち込めます。

- 大きな荷かご：運搬容量が12個増えます。
- 携帯モーター：加工速度が40%増えます。
- 修理キット：運河の近道が最初から開通します。他の島では支度金60を持ち込みます。

出発時には現地の資金・設備・スタッフ・在庫がリセットされます。道具と復旧記録は残ります。完成後の島を歩いたり、違う道具で同じ島を再プレイしたりできます。進行中の島を離れる際は確認が表示されます。

## 保存とプライバシー

進行はブラウザのlocalStorageに自動保存されます。アカウント、広告、課金、解析ツール、ゲームデータを送信するバックエンドはありません。サイト配信に必要な通常の通信はホスティング側で処理されます。

新キャンペーンは `shiokaze_workshop_v3` に保存し、直前の有効な保存を `.backup` に保持します。旧版の `snowcamp_direct_v2_1` は削除・上書きしません。旧版の有効な記録を認識した場合、道具を解放して新しい航海を開始します。旧版のお金や建物の変換はしません。

別の端末・ブラウザとは同期しません。ブラウザの保存データを消すと進行が失われます。保存禁止の環境では警告を出してプレイを継続します。

## 実行と更新

ランタイムに外部ライブラリやビルド作業は不要です。リポジトリのルートをHTTPで配信します。

```sh
python -m http.server 8000
```

ブラウザでローカルサーバーを開いてください。GitHub Pagesは `main` / `/(root)` を使用し、`.nojekyll` を維持します。変更はプルリクエストで確認してから取り込みます。

`game.js` を編集したら、CSPとSubresource Integrityを必ず更新します。

```sh
python tools/update_hash.py
node --check game.js
```

## 検証

```sh
python -m pip install playwright==1.57.0
python -m playwright install --with-deps chromium
python tests/test_game.py
```

GitHub Actionsでも実行する構成です。正常系のテストは実際のHTTP配信、ブラウザ保存、WebGL初期化、デスクトップ幅・スマホ幅、タッチ入力、資源・資金の整合性、橋の経路、スタッフ、報酬の二重実行防止、セーブの復元などを確認します。

`--in-memory` は制限された検証環境向けの代替モードで、HTTP配信や本物のストレージを検証するものではありません。スマートフォン幅の自動テストとiPhone・Android実機テストは別です。実際のプレイ時間と満足度は、人によるプレイテストで調整してください。

## 表現と権利の整理

独自の修理ロボット・島・工房・港・建造物をプログラムの図形で描き、効果音は合成しています。外部ゲームの画像、モデル、動画、音源、ロゴは同梱していません。システムフォントは参照のみで、フォントファイルを再配布しません。

これは表現の独自化と出所の整理であり、著作権・商標・特許等の権利クリアランスを保証するものではありません。仮称について商標調査は未実施です。外部素材を追加する場合は出所とライセンスを確認・記録してください。
